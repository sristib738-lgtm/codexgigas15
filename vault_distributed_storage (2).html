Architecture
Client → Router selects a placement set.
Metadata quorum records object version, placement and checksum.
Storage nodes hold immutable object chunks plus hashes.
Read repair detects stale/corrupt replicas and schedules replacement.
Rebalancer moves replicas when node capacity/health changes.
Garbage collector removes obsolete versions after the retention window.
